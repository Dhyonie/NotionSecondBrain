# Marketing system — program breakdown

Not a project. A **program**: a group of related projects run together. Parked in someday/maybe
until the second brain is running.

Decision: build it for Dio's own business first, then sell the same system to starter businesses.
His own build becomes the reference implementation and the proof it works.

Currently exists: a social presence with content. Nothing else.

## The missing root

He listed branding, website, ads, content, CRM, funnels and email. None of them can be designed
until one question is answered: **who is this for and what are you promising them?** A logo for an
undefined offer is decoration; a landing page without a promise is a brochure; ads pointed at an
unproven funnel are a way to pay to discover it doesn't convert. The formal name is **positioning**.

## Dependency order

Each stage inherits decisions from the one above. Building out of order means rebuilding.

**Foundation**
1. **Positioning & offer** — done when one page states who it's for, what problem it solves, what
   you promise, and what it costs. Cheapest project here, highest leverage. Audience definition is
   the **ICP** (ideal customer profile).
2. **Brand basics** — done when a mini brand kit exists: logo, palette, two typefaces, tone note.
   Deliberately "basics". A constraint-setter, not a destination. Canva holds brand kits natively.

**The machine**
3. **Site + first funnel** — done when one live page collects an email from a stranger. Not a
   website, one page. The exchange is a **lead magnet**: something worth having, given for an email.
4. **Email engine** — done when a new signup gets a welcome sequence automatically. Follows
   immediately behind 3; collecting emails you never send to is worse than not collecting them.
5. **CRM** — done when contacts arrive in one pipeline on their own. A CRM with no inbound flow is
   a spreadsheet with extra steps. CRMs die from over-configuration faster than anything else.

**Amplify**
6. **Content engine** — done when a repeatable weekly rhythm exists. The exception to the ordering:
   the audience already exists, so this can start immediately. It's also the free test of project 1
   — bad positioning shows up in a fortnight at no cost, where ads would cost money to learn the same.
7. **Paid ads** — done when one campaign runs with a measured cost per lead. Last on purpose. Ads
   don't create demand, they buy traffic; into an unproven funnel they just lose money faster.

**Productize**
8. **Package it to sell** — done when the whole build is written up as a process someone else could
   be walked through. A **productized service**; the written process is an **SOP**. Because his own
   build comes first, this is mostly transcription — *provided the reasoning gets captured along the
   way*. If it doesn't, he'll be reconstructing his own decisions from memory a year later, which is
   exactly the failure the second brain exists to prevent.

## If and when it becomes active

Projects 1, 2 and 6 are the ones that can run concurrently — and they're the three cheapest.
3 through 8 stay parked until the one above them finishes.
